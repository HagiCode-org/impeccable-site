## 何時使用

`/impeccable onboard` 適用於決定新使用者是否留下的時刻：第一個畫面、空狀態、設定流程、產品導覽、「現在我該做什麼」的空白。當啟動率低、新使用者在達到價值之前流失，或你的產品有空狀態只說「尚無項目」然後就停在那裡時使用。

## 運作方式

指令從一個問題開始：aha 時刻是什麼，新使用者能多快到達那裡。每個設計決策都指向那個時刻。

它處理塑造第一印象的各個面向：

1. **首次使用體驗**：註冊後的即時時刻。使用者應該看到導覽、空白畫布、填好的範例，還是什麼都不看。選擇匹配產品的方式。
2. **空狀態**：每個零資料的畫面都獲得引導。我在哪裡、為什麼是空的、下一步做什麼、滿了之後會長什麼樣。
3. **設定和安裝**：必要的設定被最小化、預設值是智慧的、每個步驟都解釋為什麼重要。
4. **漸進式揭露**：進階功能保持不礙事，直到被賺得。
5. **啟動事件**：使用者首次體驗核心價值的時刻被追蹤和安靜地慶祝。

指令抵抗兩個常見的失敗模式：過度教學的新手指引，使用者在接觸任何東西之前就點完了一個輪播；以及零新手指引，使用者被丟進一個空白應用並被期望自己摸索。

## 試試看

```
/impeccable onboard the editor
```

典型輸出：

- 首次使用：用使用者可以修改的填好範例文件替換空白編輯器。取消按鈕丟棄範例，編輯則以使用者的工作替換內容。
- 文件列表的空狀態：「尚無文件。建立你的第一份，或從 Notion、Google Docs 或 Markdown 匯入。」
- 設定：從 6 個必填欄位減少為 1 個（工作區名稱）。其他一切都有智慧預設值，可以稍後在設定中編輯。
- 啟動：使用者首次儲存文件時，安靜的提示說「已儲存。你的工作現在在雲端了。」一次性的，不重複。

## 注意事項

- **以產品導覽作為預設答案。** 大多數產品不需要導覽。它們需要一個更好的第一個畫面。導覽是拐杖。
- **沒有定義 aha 時刻就設計新手指引。** 如果你不能用一句話說出使用者在頭 60 秒應該感受到什麼，先回到 `/impeccable shape`。
- **在破碎的流程上執行 onboard。** 先修復流程。新手指引無法拯救核心操作已經損壞的產品。
