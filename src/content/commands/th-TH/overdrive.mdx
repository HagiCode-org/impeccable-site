## เมื่อไรควรใช้

`/impeccable overdrive` มีไว้สำหรับช่วงเวลาที่คุณต้องการสร้างความประทับใจ Hero ที่ใช้ WebGL ตารางที่รับมีแถวล้านแถว ไดอะล็อกที่แปรรูปจากอิลิเมนต์ทริกเกอร์ ฟอร์มที่ตรวจสอบแบบเรียลไทม์พร้อมข้อเสนอแนะแบบสตรีมมิง การเปลี่ยนหน้าที่รู้สึกเหมือนภาพยนตร์ ใช้เมื่องบโปรเจกต์อนุญาตให้ทะเยอทะยานทางเทคนิคและผลลัพธ์ต้องรู้สึกพิเศษเหนือธรรมดา

อย่าใช้บนเครื่องมือของผู้ปฏิบัติงาน แดชบอร์ด หรือสิ่งที่ความน่าเชื่อถือชนะความอลังการ Overdrive ใช้ความซับซ้อนเพื่อเอฟเฟกต์ และการแลกเปลี่ยนนั้นคุ้มค่าเฉพาะบนช่วงเวลาที่สำคัญ

## วิธีการทำงาน

สกิลเลือกหนึ่งช่วงเวลาให้พิเศษเหนือธรรมดาและมุ่งมั่นกับมัน แทนที่จะกระจายความพยายามไปทั่วอินเทอร์เฟซ จากนั้นมันเอื้อมไปถึงเทคนิคที่ UI ที่สร้างจาก AI ส่วนใหญ่ไม่เคยแตะ: เชดเดอร์ WebGL ฟิสิกส์สปริง Scroll Timeline View Transitions แอนิเมชันแคนวาส ฟิลเตอร์ที่เร่งด้วย GPU ทุกอย่างถูกงบ โปรไฟล์ และทดสอบที่ 60fps พร้อม fallback reduced-motion ใส่มาให้

ผลลัพธ์ Overdrive ประกาศด้วย `──── ⚡ OVERDRIVE ────` เพื่อให้คุณรู้ว่าคุณกำลังเข้าสู่โหมดที่ทะเยอทะยานกว่า คาดหวัง diff ที่ใหญ่กว่า  dependencies ใหม่ และความลึกของการสร้างที่เกินกว่าสกิลอื่นๆ ผลิต

## ลองใช้งาน

```
/impeccable overdrive the landing hero
```

การรันหนึ่งครั้งอาจแทนที่ hero แบบคงที่ด้วยพื้นหลังเชดเดอร์ WebGL ที่ขับเคลื่อนด้วยตำแหน่งเมาส์ หัวข้อข่าวแสดงผลที่เปิดเผยด้วยมาสก์ตามการเลื่อนโดยใช้ Scroll Timeline API และ View Transition บน CTA ที่แปรรูปเป็นหน้าถัดไป บวก fallback reduced-motion ที่สลับทั้งหมดเป็นองค์ประกอบแบบคงที่ที่สะอาด

## ข้อควรระวัง

- **ใช้ทุกที่** Overdrive ทำงานเพราะมันหายาก หากทุกหน้ามีช่วงเวลาแบบภาพยนตร์ ไม่มีอันไหนเป็นภาพยนตร์
- **ส่งมอบโดยไม่มี fallback reduced-motion** ไม่อาจเจรจาได้ Overdrive เพิ่มอัตโนมัติ; อย่าลบมัน
- **เพิกเฉอประสิทธิภาพ** ช่วงเวลาพิเศษเหนือธรรมดายังต้องถึง 60fps หากเอฟเฟกต์ทำให้เฟรมหล่น ตัดมันออกหรือเพิ่มประสิทธิภาพ ความอลังการที่ช้าแย่กว่าสิ่งที่เรียบง่ายที่ทำได้ดี
- **รัน overdrive ก่อนที่อินเทอร์เฟซฐานจะแข็งแกร่ง** ความอลังการบนฐานที่เสียอ่านเป็นการเบี่ยงเบนความสนใจ ไม่ใช่ delight
