## เมื่อไรควรใช้

`/impeccable quieter` คือตัวถ่วงน้ำหนักของ `/impeccable bolder` ใช้เมื่ออินเทอร์เฟซก้าวร้าวทางสายตา กระตุ้นมากเกินไป หรือพยายามทำหลายอย่างเกินไปที่ระดับเสียงเต็ม นีออนบนพื้นมืด ข้อความไล่สีทุกที่ 6 สีเน้น ทุกอย่างเคลื่อนไหว เงา 20px ใช้ quieter เมื่อการออกแบบต้องการหายใจและคุณต้องการการปรับปรุงโดยไม่สูญเสียจุดยืน

มีประโยชน์หลัง `/impeccable bolder` ไปไกลเกินไปเล็กน้อย

## วิธีการทำงาน

สกิลทำงานโดยการลดข้ามสี่แกน:

1. **สี**: ลดความอิ่มตัว ลด chroma ใน OKLCH ดึงสีเน้นกลับเป็นสีหลักเดียวบวกสีสนับสนุนที่ปรับโทน ไม่เกินสองสีที่ตั้งใจ
2. **คอนทราสต์**: ทำให้ส่วนมืดและสว่างสุดขั้วอ่อนลง ดึงช่วงเข้ามา พื้นหลังเปลี่ยนจากขาวบริสุทธิ์และดำบริสุทธิ์เป็นกระดาษและหมึก
3. **การตกแต่ง**: ลบเงาที่ไม่ทำงาน ทิ้งขอบที่ไม่รับโครงสร้าง ปลดเกษียณไล่สีที่มีอยู่เพื่อพลังงานแทนลำดับชั้น
4. **การเคลื่อนไหวและเอฟเฟกต์**: ชะลอแอนิเมชัน ลบทุกอย่างที่เล่นอัตโนมัติ ทิ้งพารัลแลกซ์และเบลอ เว้นแต่พวกมันรับใช้ความอ่านง่าย

สกิลรักษาเจตนาของการออกแบบ หากต้นฉบับมีจุดยืน เวอร์ชัน quieter มีจุดยืนเดียวกันที่มั่นใจมากกว่า การปรับปรุง ไม่ใช่การทำให้เป็นกลาง

## ลองใช้งาน

```
/impeccable quieter the pricing page
```

ผลลัพธ์ทั่วไป:

- ข้อความไล่สีบนราคาถูกลบ แทนที่ด้วยหมึกทึบหนักกว่าหนึ่งน้ำหนัก
- สีเน้นสามสีลดเหลือหนึ่ง (แมจเจนตา) อีกสองสีกลายเป็นตัวแปรกลาง
- เงาการ์ดลดจาก `0 20px 40px rgba(0,0,0,0.2)` เป็น `0 1px 0 var(--color-mist)` (เส้นผม)
- พื้นหลังเปลี่ยนจากไล่สีมืดเป็นกระดาษพร้อมล้างครีมอ่อนที่ด้านบน
- แอนิเมชัน hero จาก 1.2s easeOut พร้อม 3 อิลิเมนต์สแต็กเกอร์ เป็น fade-in เดียว 260ms

## ข้อควรระวัง

- **ใช้มากเกินไป** Quieter สามารถถอดบุคลิกออกได้หากคุณรันบนสิ่งที่วัดได้แล้ว ใช้เมื่อการออกแบบดังเกินไป ไม่ใช่เมื่อมันยืนยันอย่างถูกต้อง
- **สับสน quieter กับ distill** Quieter ลดความเข้มข้น Distill ลบอิลิเมนต์ พวกมันเป็นการเคลื่อนไหวที่แตกต่างกัน
- **รันเพื่อตอบสนองต่อ critique ที่บอกว่า "ยุ่งเกินไป"** ยุ่งมักหมายถึงมีหลายอย่างเกินไป ไม่ใช่ดังเกินไป ลอง `/impeccable distill` ก่อน
