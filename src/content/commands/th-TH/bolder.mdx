## เมื่อไรควรใช้

ใช้ `/impeccable bolder` เมื่ออินเทอร์เฟซดูเหมือนทุกอินเทอร์เฟซอื่น ฟอนต์ sans ทั่วไป น้ำหนักกลาง เงาอ่อน สีเน้นพอประมาณ ระยะห่างที่สมเหตุสมผล จำไม่ได้ การออกแบบไม่ได้ผิด แค่ปลอดภัย ใช้ bolder เมื่อโปรเจกต์สามารถรับการมีอยู่ได้และสถานะปัจจุบันไม่ได้นำเสนออะไรเลย

อย่าใช้บนแดชบอร์ดที่ผู้คนจ้องมองเป็นชั่วโมง ความกล้าหาญหาเหตุผลได้บนหน้าการตลาด ช่วงเวลา hero และฟีเจอร์เนื้อหา ไม่ใช่ในเครื่องมือของผู้ปฏิบัติงาน

## วิธีการทำงาน

สกิลขยายสี่แกนโดยไม่ทำลายความใช้งานได้:

1. **สเกล**: ตัวอักษรแสดงผลถูกผลักไปที่ clamp(3rem, 6vw, 6rem) หรือมากกว่า หัวข้อข่าวที่เติมวิวพอร์ต ไม่ใช่หลีกเลี่ยงมัน
2. **คอนทราสต์น้ำหนัก**: อ่อน 300 กับหนัก 800 แทนกลางกับปกติ ความตึงเครียดจริง ไม่ใช่การส่งสม
3. **ความมุ่งมั่นด้านสี**: สีเน้นปรากฏที่ความแรงเต็ม ไม่ได้เจือจาง พื้นหลังสามารถยึดจุดยืน (หมึก สีเน้น ครีม) แทนกระดาษทั้งหมด
4. **ความมั่นใจในการจัดวาง**: ความไม่สมมาตร นอกกริด คำคมดึง วรรคตอนห้อย การกระโดดของสเกล เลย์เอาต์มีเสียง

สกิลไม่ได้เพิ่มเพิ่มเติม มันขยายสิ่งที่มีอยู่แล้ว หากการออกแบบมีสามสี bolder ไม่ได้เพิ่มสีที่สี่ มันมุ่งมั่นกับสามสีนั้นมากขึ้น

## ลองใช้งาน

```
/impeccable bolder the landing page hero
```

การเปลี่ยนแปลงที่คาดหวัง:

- หัวข้อ hero จาก 3rem เป็น clamp(3.5rem, 7vw, 6.5rem), ฟอนต์แสดงผล, น้ำหนัก 700
- หัวข้อรองจากปกติเป็นตัวเอียงที่ 1.5rem ดึงไปซ้าย 8px จากหัวข้อเพื่อการจัดเรียงแบบออปติคัล
- พื้นหลังเปลี่ยนจากกระดาษเป็นไล่สีครีมถึงกระดาษ สร้างคอนเทนเนอร์ที่อบอุ่นกว่า
- ปุ่ม CTA เติมเต็ม ลบเงาทิ้ง ลดรัศมีขอบ สถานะ hover กลับสี
- ภาพสนับสนุนดันออกนอกกริดเล็กน้อยด้วย margin บนติดลบ สร้างความไม่สมมาตร

## ข้อควรระวัง

- **รันบนหน้าผิด** แดชบอร์ดผลิตภัณฑ์ การตั้งค่า และฟอร์มไม่ควรเป็น bold พวกมันควรอ่านได้ ใช้ `/impeccable layout` หรือ `/impeccable polish` แทน
- **สับสน bold กับ loud** Bold หมายถึงมุ่งมั่นและมั่นใจ Loud หมายถึงการตะโกน Bolder คือข้อแรก หากผลลัพธ์รู้สึกก้าวร้าว ตามด้วย `/impeccable quieter`
- **จับคู่กับ `/impeccable delight` ในพาสเดียวกัน** Delight ทำงานได้ดีที่สุดกับฐานภาพที่มั่นคง Bold ก่อน ทำให้มั่นคง แล้ว delight
