## Wann man es verwendet

`/impeccable distill` entfernt, was nicht dorthin gehört. Konkurrierende Buttons, redundante Informationen, dekorative Rahmen, drei Schriften wo eine funktioniert, sechs Navigationselemente wo drei hingehören. Verwenden Sie es, wenn ein Interface überladen, beschäftigt wirkt oder versucht, zu viel auf einmal zu tun.

Greifen Sie zu ihm, nachdem `/impeccable critique` „kognitive Belastung" oder „visuelles Rauschen" markiert hat, oder jederzeit, wenn eine Seite durch Anhäufung gewachsen ist und niemand das Editieren vorgenommen hat.

## Wie es funktioniert

Der Skill beginnt mit einer Frage: was ist die einzelne Aufgabe, die dieses Interface zu erledigen versucht? Alles, was dieser Aufgabe nicht hilft, kommt auf die Abschussliste.

Er arbeitet in zwei Durchgängen:

1. **Die Komplexitätsquellen bewerten**. Zu viele Elemente, übermäßige Variation, Informationsüberflutung, visuelles Rauschen, verwirrende Hierarchie, Feature-Creep. Jede benennen.
2. **Rücksichtslos editieren**. Entfernen, was nicht wesentlich ist. Kombinieren, was kombiniert werden kann. Verbergen, was warten kann. Variation zu einer einzigen Behandlung konsolidieren. Auf eine einzige visuelle Sprache festlegen.

Das Prinzip: jedes Element auf der Seite muss seine Existenz rechtfertigen. Weniger Hindernisse, nicht weniger Features.

## Ausprobieren

```
/impeccable distill this dashboard
```

Vorher: vier Kartenstile, drei Button-Varianten, zwei Header-Behandlungen, eine Sidebar mit 14 Elementen in 5 Gruppen.

Nach einem `/distill`-Durchlauf, typische Änderungen:

- Die vier Kartenstile zu einem zusammenfassen
- Eine Button-Variante wählen, die anderen zu Text-Links herabstufen
- Die Header vereinheitlichen
- Sidebar in 3 statt 5 Gruppen gliedern
- Erweiterte Optionen hinter einer Aufklapp-Funktion verstecken

Weniger Dinge. Jedes klarer.

## Fallstricke

- **Verwechslung von distill mit delete.** Distill entfernt Hindernisse. Es entfernt keine Features, die Nutzer brauchen. Wenn ein Nutzer täglich auf etwas angewiesen ist, finden Sie einen Weg, es leise zu behalten, nicht einen Weg, es zu kürzen.
- **Zu früh ausführen.** Wenn das Feature noch wächst, bedeutet distillen jetzt, dass Sie dieselbe Sache nächste Woche nochmal distillen. Warten Sie, bis die Form stabil ist.
- **Erwarten, dass es Hierarchie-Arbeit ersetzt.** Manchmal ist die richtige Lösung nicht das Entfernen von Dingen, sondern das Anordnen. Greifen Sie zu `/impeccable layout`, wenn das Problem das Layout ist, nicht die Menge.
