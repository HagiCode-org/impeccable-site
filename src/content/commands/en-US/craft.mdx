## When to use it

Use `craft` for new work where the design direction is not yet settled. It pays the upfront cost of shaping the work before code starts.

## What it changes

The flow asks discovery questions, locks a brief, builds against that brief, and then visually iterates instead of stopping at the first working implementation.

## What good looks like

You should end up with a feature that feels intentionally designed rather than merely assembled.
