## Best timing

Use `teach` near the start of a project or when the current design context is fragmented across conversations.

## What it produces

The command should record register, users, purpose, principles, and eventually visual system guidance so later runs can stay aligned.

## Why it matters

Stable context raises the floor for every later command.
