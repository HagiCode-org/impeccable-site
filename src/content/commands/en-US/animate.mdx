## Right moment

Use `animate` after the static layout is already coherent. Motion works best when it reinforces a structure that already makes sense.

## Focus

Good motion should clarify, pace, and reward. It should not exist only because animation is available.

## Guardrail

Purpose beats volume. The best runs make a page feel more legible, not merely more active.
