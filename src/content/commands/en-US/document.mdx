## Best fit

Choose `document` when the project already has enough UI that the visual system can be observed rather than invented.

## Expected result

The output should capture the design tokens and recurring component patterns in a form that later commands can follow.

## Follow-up

Once the system is documented, `extract` becomes easier and safer.
