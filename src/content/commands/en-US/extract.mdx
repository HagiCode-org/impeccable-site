## Best use case

Use `extract` when inconsistency is no longer accidental and now has a maintenance cost.

## What it should pull together

Expect recurring spacing rules, typography choices, controls, and layout motifs to be grouped into clearer reusable primitives.

## Goal

Future work should need fewer one-off visual decisions.
