## When to reach for it

`/impeccable` is the broad command surface. Use it when the problem is real but the exact workflow is still fuzzy.

## What to bring

Describe the surface, the user, and the quality bar. If the project already has `PRODUCT.md` and `DESIGN.md`, this command can anchor to that context instead of starting from generic defaults.

## Expected outcome

The command should converge on a stronger direction, then either build directly or route into a tighter follow-up such as `craft`, `critique`, or `polish`.
