## When to use it

Choose `onboard` when activation is the real product problem. It is less about decoration and more about momentum.

## What it should improve

The command can reshape welcome steps, contextual hints, empty states, and first-run copy so users understand what to do next.

## Goal

The user should hit value sooner and with less confusion.
