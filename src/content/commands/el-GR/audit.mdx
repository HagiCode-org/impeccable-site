## Πότε να τη χρησιμοποιήσετε

Το `/impeccable audit` είναι το τεχνικό αντίστοιχο του `/impeccable critique`. Όπου το `/impeccable critique` ρωτά «νιώθετε σωστά αυτό», το `/impeccable audit` ρωτά «αντέχει αυτό». Εκτελεί ελέγχους προσβασιμότητας, απόδοσης, θεματολογίας, responsive σχεδιασμού и αντι-προτύπων έναντι της υλοποίησης, βαθμολογεί κάθε διάσταση 0 έως 4, и παράγει ένα σχέδιο με κατατάξεις σοβαρότητας P0 έως P3.

Χρησιμοποιήστε το πριν την αποστολή, κατά τη διάρκεια ενός sprint ποιότητας, ή όταν ένας tech lead λέει «πρέπει πραγματικά να κοιτάξουμε την προσβασιμότητα».

## Πώς λειτουργεί

Η δεξιότητα σαρώνει τον κώδικά σας σε πέντε διαστάσεις:

1. **Προσβασιμότητα**: αντίθεση WCAG, ARIA, πλοήγηση πληκτρολογίου, σημασιολογικό HTML, ετικέτες φορμών.
2. **Απόδοση**: ταλαιπωρία διάταξης, ακριβοί animations, έλλειψη lazy loading, μέγεθος bundle.
3. **Θεματολογία**: hardcoded χρώματα, κάλυψη dark mode, συνοχή tokens.
4. **Responsive**: συμπεριφορά breakpoints, touch targets, διαχείριση mobile viewport.
5. **Анти-πρότυπα**: οι ίδιοι 25 ντετερμινιστικοί έλεγχοι που εκτελεί ο ανιχνευτής.

Κάθε διάσταση παίρνει βαθμολογία 0 έως 4. Κάθε εύρημα παίρνει σοβαρότητα: P0 μπλοκάρει την κυκλοφορία, P1 πρέπει να διορθωθεί αυτό το sprint, P2 είναι για τον επόμενο κύκλο, P3 είναι φινίρισμα. Λαμβάνετε ένα έγγραφο που μπορείτε να επικολλήσετε σε ένα σύστημα παρακολούθησης tickets.

Το Audit δεν διορθώνει τίποτα. Τεκμηριώνει. Δρομολογήστε τα ευρήματα στο `/impeccable polish`, `/impeccable harden` ή `/impeccable optimize` ανάλογα με την κατηγορία.

## Δοκιμάστε το

```
/impeccable audit the checkout flow
```

Αναμενόμενο αποτέλεσμα:

```
Προσβασιμότητα: 2/4 (μερική)
  P0: Λείπουν ετικέτες φορμών σε 4 πεδία
  P1: Αντίθεση 3.1:1 στην κατάσταση απενεργοποιημένου κουμπιού
  P2: Κανένας ορατός δείκτης εστίασης στο προσαρμοσμένο dropdown

Απόδοση: 3/4 (καλή)
  P1: Η εικόνα hero δεν έχει lazy-load (340KB)
  ...
```

Δώστε τα P0 στο `/impeccable harden`, τα P1 θεματολογίας και τυπογραφίας στο `/impeccable typeset` και `/impeccable polish`, τα υπόλοιπα στο `/impeccable polish`.

## Παγίδες

- **Σύγχυση με το `/impeccable critique`.** Το Audit είναι ποιότητα υλοποίησης. Η Critique είναι ποιότητα σχεδιασμού. Εκτελέστε και τα δύο για πλήρη εικόνα.
- **Διόρθωση P3 πριν P0.** Η κλίμακα σοβαρότητας υπάρχει για κάποιο λόγο. Ξεκινήστε από την κορυφή.
- **Παράλειψη των διαστάσεων που νομίζετε ότι είναι εντάξει.** Η θεματολογία και το responsive είναι αυτές που οι περισσότεροι υποθέτουν ότι είναι εντάξει μέχρι να αποδειχθεί ότι δεν είναι.
