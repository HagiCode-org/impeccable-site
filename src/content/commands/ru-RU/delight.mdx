## Когда использовать

`/impeccable delight` — для интерфейсов, которые работают, но ничего не ощущаются. Используйте, когда основной опыт надёжен и вы хотите добавить маленькие человеческие штрихи, которые заставят людей запомнить его: продуманное пустое состояние, загрузочное сообщение с характером, анимация успеха, которая ощущается заслуженной, момент микрокопирайтинга, вызывающий улыбку.

Это навык завершения. Никогда не первое, что вы запускаете на новой сборке.

## Как это работает

Навык ищет возможности для delight в местах, которые большинство дизайнеров пропускают:

1. **Пустые состояния**: вместо «Пока нет элементов» — что-то с индивидуальностью, подходящей бренду.
2. **Моменты загрузки и ожидания**: лучшие продукты превращают ожидание в контент.
3. **Обратная связь при успехе**: момент празднования, когда происходит что-то заслуживающее празднования.
4. **Микрокопирайтинг**: подписи кнопок, подсказки, сообщения об ошибках, плейсхолдеры. Крошечные тексты со вкусом.
5. **Пасхалки и вторичные состояния**: вещи, которые пользователи обнаруживают и которые награждают внимательность.

Навык читает фирменный тон из `PRODUCT.md`. Серьёзный аналитический инструмент получает серьёзный delight (сухой, точный, немного умный). Игривое потребительское приложение получает более выраженную индивидуальность. Он не навязывает юмор там, где юмор не подходит аудитории.

Правило: каждый момент delight должен по-прежнему идеально работать, если удалить сам delight. Ничто не зависит от улыбки.

## Попробуйте

```
/impeccable delight the first-run experience
```

Ожидаемые добавления:

- Пустой дашборд заменяет «Пока нет данных» на «Ваш дашборд пока пуст. Давайте это исправим.» плюс один CTA.
- Начальная синхронизация получает 3-ступенчатое загрузочное сообщение: «Ищем ваши аккаунты... / Загружаем последние 30 дней... / Наводим красоту...».
- Первое успешное действие вызывает одноразовый тост с маленьким праздничным моментом. После — просто тихая галочка.
- Всплывающая подсказка на сложном поле написана так, будто её написал живой человек.

## Подводные камни

- **Навязывание юмора.** Не каждый бренд игривый. Если фирменный голос в `PRODUCT.md` — «клинический и точный», delight добавляет умную сдержанность, а не шутки.
- **Чрезмерное украшение.** Один момент delight запоминается. Двадцать становятся шумом. Навык намеренно консервативен.
- **Запуск delight до polish.** Polish исправляет то, что не так. Delight добавляет то, чего не хватает. В таком порядке.
