## Когда использовать

`/impeccable` — это базовая команда. Вызывайте её напрямую, когда хотите свободную работу над дизайном с загруженным полным справочником, без выбора специализированной команды. Это запасной вариант, к которому вы обращаетесь, когда ни один из 23 специалистов (`audit`, `polish`, `critique` и остальные) точно не подходит для вашей задачи.

Обращайтесь к `/impeccable` напрямую, когда:

- **Вы не уверены, какая команда подходит.** Опишите, что хотите, простым языком, и пусть навык выберет правильный подход.
- **Работа охватывает несколько дисциплин.** «Переделать этот hero-блок» затрагивает макет, типографику, цвет и анимацию. Одна команда не может охватить всё.
- **Вы хотите полный интеллект дизайна без ограничений.** Все справочные файлы загружены, все антипаттерны проверены, без предустановленного рабочего процесса.

Для структурированных процессов используйте специализированные команды в боковой панели. Сначала запустите `/impeccable teach` в любом новом проекте, чтобы создать PRODUCT.md и DESIGN.md. `/impeccable craft` связывает интервью-исследование в полный процесс сборки с живой визуальной итерацией. `/impeccable shape` создаёт дизайн-бриф без написания кода. `/impeccable live` даёт вам выборщик в браузере с тремя вариантами для каждого элемента. Команды оценки и доработки (`audit`, `critique`, `polish`, `typeset`, `layout`, `colorize` и остальные) отвечают каждая за свою часть работы.

## Как это работает

Большинство ИИ-генерируемых интерфейсов ломаются одинаково: стандартные шрифты, фиолетовые градиенты, сетки из карточек поверх сеток из карточек, стеклоформа повсюду. `/impeccable` даёт вашему ИИ сильную точку зрения. Он загружает субъективный справочник дизайна плюс длинный список антипаттернов, а затем побуждает модель принять конкретное эстетическое направление до написания первой строки кода.

Два файла в корне вашего проекта определяют всё, что делает навык:

- **`PRODUCT.md`** содержит регистр (бренд или продукт), целевых пользователей, фирменный стиль, антиреференсы, принципы дизайна. Отвечает на вопросы «кто, что, зачем».
- **`DESIGN.md`** содержит цвета, типографику, возвышение, компоненты, правила «делай и не делай» в шестисекционном формате Google Stitch. Отвечает на вопрос «как это выглядит».

Каждая команда читает оба файла перед генерацией. **Регистр** определяет, какие значения по умолчанию загружаются. Брендовые (маркетинг, лендинги, портфолио, где дизайн и есть продукт) и продуктовые (интерфейсы приложений, дашборды, инструменты, где дизайн служит продукту) имеют разные значения по умолчанию для типографики, анимации, цвета и плотности. Указание регистра один раз в PRODUCT.md означает, что `/impeccable typeset` не будет навязывать шрифты редакторского журнала дашборду и не будет предлагать продуктовые умолчания для кампании. См. [руководство по бренду и продукту](/tutorials/brand-vs-product), чтобы понять, как они различаются.

При первом использовании в проекте навык автоматически запускает поток `teach`: короткое интервью, которое создаёт PRODUCT.md, а затем делегирует `/impeccable document` для DESIGN.md. Последующие команды читают файлы без повторных вопросов.

## Попробуйте

```
/impeccable redo this hero section
```

```
/impeccable build me a pricing page for a developer tool
```

Оба промпта намеренно размытые. `/impeccable` выберет сильное эстетическое направление, соответствующее вашему регистру, выберет нестандартные шрифты, избежит ИИ-палитры и примет те конкретные решения, которые принял бы дизайнер. Не нужно сначала выбирать команду, не нужно следовать пошаговому процессу.

Для визуальной итерации в браузере, а не в чате:

```
/impeccable live
```

Выберите любой элемент на запущенном dev-сервере. Оставьте комментарий или нарисуйте штрих. Получите три production-качественных варианта, подгруженных через HMR. Примите нужный — и он запишется в исходный код.

## Закрепите команды как ярлыки

v3.0 объединила 18 отдельных навыков в единый `/impeccable` с 23 подкомандами. Если вам не хватает короткой формы конкретной команды, закрепите её обратно:

```
/impeccable pin critique
```

С этого момента `/critique` вызывает `/impeccable critique` напрямую. Он создаёт лёгкий навык-перенаправление, который делегирует родительской команде, поэтому обновления навыка применяются без повторного закрепления.

Полезные ярлыки для尝试:

- `/impeccable pin polish` для финальной доработки
- `/impeccable pin audit` для детерминированных проверок a11y/производительности
- `/impeccable pin live` для итерации в браузере
- `/impeccable pin critique` для ревью дизайна

Для удаления: `/impeccable unpin critique`. Ярлыки хранятся как директории с префиксом `i-` в папке навыков вашего харнеса (`.claude/skills/i-critique/`, `.cursor/skills/i-critique/` и т.д.), поэтому вы также можете удалить их вручную.

## Подводные камни

- **Восприятие как стайлгайд.** Это субъективный дизайнерский партнёр, а не линтер. Значения по умолчанию существуют для повышения планки, а не для отмены ваших решений. Если у вас есть реальная причина возразить (фирменные стандарты, ограничения доступности, пользовательские исследования), возражайте и объясните почему. Навык будет работать с вами. Что ухудшает результат — это игнорирование мнения без причины.
- **Ожидание исправления существующего кода.** `/impeccable` предназначен для создания. Для доработки используйте `/impeccable polish`, `/impeccable distill` или `/impeccable critique`.
- **Запуск до того, как `teach` сохранил контекст.** На новом проекте он проведёт интервью прямо в процессе работы — это нормально, но медленнее. Запуск `/impeccable teach` как самой первой команды немного плавнее.
- **Пропуск вопроса о регистре.** Значения по умолчанию для бренда и продукта расходятся достаточно, чтобы работа с неправильным регистром давала тонко неверный результат. Если в `PRODUCT.md` нет поля `## Register` (устаревший формат), запустите `/impeccable teach`, чтобы добавить его.
