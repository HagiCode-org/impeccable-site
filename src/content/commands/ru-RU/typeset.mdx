## Когда использовать

Обращайтесь к `/impeccable typeset`, когда текст на странице выглядит как типографика по умолчанию, а не как продуманная типографика. Размытая иерархия, три размера, которые выглядят одинаково, основной текст на 14px, заголовочный шрифт, который на самом деле просто Inter bold, заголовки без внимания к кернингу.

Типичные триггеры: «иерархия кажется плоской», «читаемость хромает», «шрифты выглядят стандартно».

## Как это работает

Навык оценивает типографику по пяти измерениям:

1. **Выбор шрифтов**: используете ли вы невидимые умолчания (Inter, Roboto, Arial, Open Sans), соответствует ли гарнитура бренду, более ли 2–3 семейств.
2. **Иерархия**: отличаются ли заголовки, основной текст и подписи с первого взгляда, контраст размеров составляет хотя бы 1.25x между уровнями, контраст весов читаем.
3. **Размеры и масштаб**: есть ли связная типографическая шкала, соответствует ли основной текст минимуму 16px, фиксированная rem-шкала для UI приложений или плавная clamp-шкала для маркетинговых страниц.
4. **Читаемость**: длина строки 45–75 символов, межстрочный интервал настроен для шрифта и контекста, контраст.
5. **Согласованность**: одинаковый элемент использует одинаковое оформление везде, нет единичных переопределений font-size.

Затем он исправляет найденное: выбирает выразительные гарнитуры, строит модульную шкалу, увеличивает контраст иерархии, устанавливает правильную длину строки и межстрочный интервал.

## Попробуйте

```
/impeccable typeset the article layout
```

Ожидаемый diff:

- Заголовочный шрифт заменён с Inter 700 на настоящий display-шрифт
- Типографическая шкала перестроена: 3rem / 2rem / 1.25rem / 1rem / 0.875rem, соотношение 1.333
- Основной текст увеличен с 14px до 16px
- Длина строки ограничена до 68ch в колонке статьи
- Межстрочный интервал 1.6 для основного текста, 1.1 для заголовков
- Удалены четыре единичных значения `font-size`, разбросанных по стилям компонентов

## Подводные камни

- **Запрос нового шрифта без контекста.** Typeset выбирает на основе фирменного голоса из `PRODUCT.md`. Если вы не запустили `/impeccable teach`, предложение будет стандартным.
- **Обращение к typeset, когда проблема в макете.** Если абзацы в порядке, но страница кажется тесной, вам нужен `/impeccable layout`.
- **Ожидание плавных clamp-шкал на UI приложений.** Typeset использует фиксированные rem-шкалы для интерфейсов приложений. Плавная типографика — для маркетинговых и контентных страниц, где длина строки сильно варьируется.
