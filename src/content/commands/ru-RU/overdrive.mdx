## Когда использовать

`/impeccable overdrive` — для моментов, когда вы хотите впечатлить. Hero на WebGL. Таблица на миллион строк. Диалог, который морфируется из своего триггерного элемента. Форма с валидацией в реальном времени и потоковой обратной связью. Переход между страницами, который ощущается кинематографично. Используйте, когда бюджет проекта позволяет технические амбиции и результат должен ощущаться выдающимся.

Не используйте на операторских инструментах, дашбордах или чём-либо, где надёжность важнее зрелищности. Overdrive тратит сложность на эффект, и этот компромисс оправдан только на значимых моментах.

## Как это работает

Навык выбирает один момент, чтобы сделать его выдающимся, и привержен ему, а не распределяет усилия по всему интерфейсу. Затем он обращается к техникам, которых большинство ИИ-генерируемых UI никогда не касаются: WebGL-шейдеры, spring-физика, Scroll Timeline, View Transitions, canvas-анимация, GPU-ускоренные фильтры. Всё бюджетировано, профилировано и протестировано на 60fps, с встроенными fallback'ами для reduced-motion.

Результат Overdrive объявляется через `──── ⚡ OVERDRIVE ────`, чтобы вы знали, что входите в более амбициозный режим. Ожидайте большие diff'ы, новые зависимости и глубину реализации, превышающую другие навыки.

## Попробуйте

```
/impeccable overdrive the landing hero
```

Один конкретный запуск может заменить статический hero на фон с WebGL-шейдером, управляемым позицией мыши, заголовок, который раскрывается маской при прокрутке через Scroll Timeline API, и View Transition на CTA, который морфируется на следующую страницу. Плюс fallback для reduced-motion, который заменяет всё на чистую статичную композицию.

## Подводные камни

- **Использование повсюду.** Overdrive работает, потому что он редок. Если на каждой странице кинематографические моменты, ни один из них не кинематографический.
- **Публикация без fallback'ов для reduced-motion.** Обязательно. Overdrive добавляет их автоматически; не удаляйте.
- **Игнорирование производительности.** Выдающиеся моменты всё равно должны работать на 60fps. Если эффект теряет кадры, урезайте или оптимизируйте. Медленное зрелище хуже простого, но качественного.
- **Запуск overdrive до того, как базовый интерфейс готов.** Зрелище на сломанном фундаменте воспринимается как отвлечение, а не delight.
