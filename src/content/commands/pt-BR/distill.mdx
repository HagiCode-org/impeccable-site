## Quando usar

`/impeccable distill` remove o que não deveria estar lá. Botões competindo, informação redundante, bordas decorativas, três fontes onde uma funciona, seis itens de navegação onde três pertencem. Use quando uma interface parece bagunçada, ocupada, ou como se estivesse tentando fazer coisas demais ao mesmo tempo.

Use após `/impeccable critique` sinalizar "carga cognitiva" ou "ruído visual", ou qualquer momento em que uma página cresceu por acréscimo e ninguém fez a edição.

## Como funciona

A skill parte de uma pergunta: qual é o único trabalho que esta interface está tentando fazer? Tudo que não ajuda esse trabalho está no bloco de corte.

Ela funciona em duas passadas:

1. **Avaliar as fontes de complexidade**. Muitos elementos, variação excessiva, sobrecarga de informação, ruído visual, hierarquia confusa, feature creep. Nomeie cada um.
2. **Editar implacavelmente**. Remover o que não é essencial. Combinar o que pode ser combinado. Esconder o que pode esperar. Consolidar variação em um único tratamento. Comprometer-se com uma única linguagem visual.

O princípio: cada elemento na página precisa justificar sua existência. Menos obstáculos, não menos funcionalidades.

## Experimente

```
/impeccable distill this dashboard
```

Antes: quatro estilos de card, três variantes de botão, dois tratamentos de header, uma barra lateral com 14 itens agrupados em 5 seções.

Após uma passada de `/distill`, mudanças típicas:

- Colapsar os quatro estilos de card em um
- Escolher uma variante de botão, rebaixar as outras para text links
- Unificar os headers
- Agrupar a barra lateral em 3 seções, não 5
- Esconder opções avançadas atrás de um disclosure

Menos coisas. Cada uma mais clara.

## Armadilhas

- **Confundir distill com delete.** Distill remove obstáculos. Não remove funcionalidades que os usuários precisam. Se um usuário depende de algo diariamente, encontre uma forma de mantê-lo discretamente, não uma forma de cortá-lo.
- **Executar muito cedo.** Se a funcionalidade ainda está crescendo, destilar agora significa destilar a mesma coisa novamente na próxima semana. Espere até que a forma esteja estável.
- **Esperar que substitua trabalho de hierarquia.** Às vezes a correção certa não é remover coisas, é organizá-las. Use `/impeccable layout` quando o problema é layout, não quantidade.
