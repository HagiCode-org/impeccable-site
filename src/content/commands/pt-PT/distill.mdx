## Quando utilizar

`/impeccable distill` remove o que não deveria lá estar. Botões em competição, informação redundante, bordas decorativas, três tipos de letra onde um funciona, seis itens de navegação onde três pertencem. Utilize-o quando um interface parece desordenado, ocupado, ou como se estivesse a tentar fazer demasiado ao mesmo tempo.

Recorra a ele depois de `/impeccable critique` sinalizar "carga cognitiva" ou "ruído visual", ou sempre que uma página cresceu por acumulação e ninguém fez a edição.

## Como funciona

A competência parte de uma pergunta: qual é a única função que este interface está a tentar desempenhar? Tudo o que não ajuda essa função está no bloco de corte.

Trabalha em duas passagens:

1. **Avaliar as fontes de complexidade.** Demasiados elementos, variação excessiva, sobrecarga de informação, ruído visual, hierarquia confusa, feature creep. Nomear cada um.
2. **Editar implacavelmente.** Remover o que não é essencial. Combinar o que pode ser combinado. Esconder o que pode esperar. Consolidar variação num único tratamento. Comprometer-se com uma única linguagem visual.

O princípio: cada elemento na página tem de justificar a sua existência. Menos obstáculos, não menos funcionalidades.

## Experimente

```
/impeccable distill this dashboard
```

Antes: quatro estilos de cartas, três variantes de botões, dois tratamentos de cabeçalho, uma barra lateral com 14 itens agrupados em 5 secções.

Após uma passagem de `/distill`, alterações típicas:

- Colapsar os quatro estilos de cartas num único
- Escolher uma variante de botão, demover as restantes para ligações de texto
- Unificar os cabeçalhos
- Agrupar a barra lateral em 3 secções, não 5
- Esconder opções avançadas atrás de uma disclosure

Menos coisas. Cada uma mais clara.

## Armadilhas

- **Confundir distill com delete.** Distill remove obstáculos. Não remove funcionalidades de que os utilizadores necessitam. Se um utilizador depende de algo diariamente, encontre forma de o manter discretamente, não forma de o cortar.
- **Executá-lo demasiado cedo.** Se a funcionalidade ainda está a crescer, destilar agora significa destilar a mesma coisa na semana seguinte. Espere até a forma estar estável.
- **Esperar que substitua o trabalho de hierarquia.** Por vezes a correção certa não é remover coisas, é organizá-las. Recorra a `/impeccable layout` quando o problema é o layout, não a quantidade.
