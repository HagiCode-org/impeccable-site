## 사용 시기

`/impeccable overdrive`은 인상을 주고 싶은 순간을 위한 것입니다. WebGL을 사용하는 히어로. 백만 행을 처리하는 테이블. 트리거 요소에서 변형되는 대화상자. 스트리밍 피드백으로 실시간 검증하는 폼. 시네마틱하게 느껴지는 페이지 전환. 프로젝트 예산이 기술적 야망을 허용하고 결과가 비범하게 느껴져야 할 때 사용하세요.

운영 도구, 대시보드, 또는 신뢰성이 스펙터클을 이기는 곳에는 사용하지 마세요. Overdrive는 효과를 위해 복잡성을 태우며, 그 트레이드오프는 중요한 순간에서만 가치가 있습니다.

## 작동 방식

스킬은 전체 인터페이스에 노력을 분산시키는 대신, 하나의 순간을 비범하게 만들기 위해 커밋합니다. 그런 다음 대부분의 AI 생성 UI가 절대 건드리지 않는 기술에 도달합니다: WebGL 셰이더, 스프링 물리, Scroll Timeline, View Transitions, 캔버스 애니메이션, GPU 가속 필터. 모든 것이 예산 책정, 프로파일링, 60fps로 테스트되며, reduced-motion 대체가 기본 제공됩니다.

Overdrive 출력은 `──── ⚡ OVERDRIVE ────`로 표시되어 더 야심 찬 모드에 진입했음을 알립니다. 더 큰 diff, 새로운 의존성, 다른 스킬이 생성하는 것 이상의 구현 깊이를 예상하세요.

## 직접 해보기

```
/impeccable overdrive the landing hero
```

구체적인 실행 예시: 정적 히어로를 마우스 위치로 구동되는 WebGL 셰이더 배경, Scroll Timeline API를 사용하여 스크롤 시 마스크로 드러나는 디스플레이 헤드라인, 그리고 CTA에서 다음 페이지로 변형되는 View Transition으로 교체. 거기에 모든 것을 깔끔한 정적 구성으로 교체하는 reduced-motion 대체까지.

## 주의 사항

- **어디에나 사용하기.** Overdrive는 드물기 때문에 작동합니다. 모든 페이지에 시네마틱 순간이 있다면 그중 어느 것도 시네마틱이 아닙니다.
- **reduced-motion 대체 없이 출시하기.** 협상 불가합니다. Overdrive는 자동으로 추가합니다. 제거하지 마세요.
- **퍼포먼스 무시하기.** 비범한 순간도 여전히 60fps를 달성해야 합니다. 이펙트가 프레임을 떨어뜨리면 줄이거나 최적화하세요. 느린 스펙터클은 잘 된 심플보다 못합니다.
- **기반 인터페이스가 탄탄하기 전에 overdrive 실행하기.** 부서진 기반 위의 스펙터클은 기쁨이 아닌 주의 산만으로 읽힙니다.
