Documentation site for the `impeccable` command surface, published at https://impeccable.hagicode.com.

The site is a browsable, localized reference for the commands of the upstream [`impeccable`](https://github.com/pbakaus/impeccable) project. Readers can scan the full command catalog, see what each command is for, and open a detail page for any command. Command content comes from the upstream project; this site presents it in its own docs shell.

## What you can do

- Browse the command catalog and find the command you need.
- Open a detail page for any command.
- Switch the site language. The site is published in many languages, and some pages fall back to English where a translation is not available.
- Subscribe to the documentation RSS feed.
